Edifyce is a tool for the digitisation of mathematics, with the mission of creating a verified library of definitions and proofs which are readable by both humans and computers.

Human Readable

Definitions can be made to correspond with TeX notation, to allow proofs to be written in a familiar language and be presented naturally.

Computer Verifiable

All proofs are given within formal systems whose rules of inference are encoded, and therefore can be computer validated.

Proofs can reference previously proven results, and so can be built on one another to perform higher-level mathematics.
